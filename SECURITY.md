# Security policy

## Supported versions

No version of `@santi020k/eslint-config-santi020k` receives security updates. The package is deprecated and its dependency graph contains known advisories.

Migrate to [`@santi020k/eslint-config-basic`](https://www.npmjs.com/package/@santi020k/eslint-config-basic), which is the maintained successor.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting for a repository-specific vulnerability that is not already covered by a published dependency advisory. Do not publish exploit details in an issue.

Reports about the maintained successor should be filed privately in the [`eslint-config-basic` repository](https://github.com/santi020k/eslint-config-basic/security).
